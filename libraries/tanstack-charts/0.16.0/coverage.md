# TanStack Charts documentation coverage

This map records what the 2026-08-31 indexing batch covers and, just as importantly, where it stops. The exact release ref is the authority. Hosted `latest` pages are moving references and are not used to silently extend this version.


## Indexed in this batch

- Stability, installation, React quick start, core grammar, integrity, responsive/SSR, interactions, transforms, common recipes, migration/testing, and primary API boundaries

## Deferred

- The remaining authored examples: financial, spatial, network, polar, heatmap, annotation, and theme/motion compositions
- Every individual mark reference and non-React framework adapter
- Custom marks/renderers, exporting, AI authoring, bundle analysis, and the complete scene/type reference

## Not present in the exact-version documentation

- A stable 1.x compatibility guarantee
- A standalone anti-pattern guide; constraints are distributed among task guides
- Automatic data fetching, cleaning, profiling, or chart recommendation

## Stopping point

This batch stops at the prioritized implementation paths above. Deferred material should be added only when a task needs it, using the same immutable ref and one retrieval-oriented page per coherent topic. Generated symbol references remain discoverable through the official index; they are grouped here rather than copied one file per symbol.
