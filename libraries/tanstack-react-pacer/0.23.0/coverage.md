# TanStack React Pacer documentation coverage

This map records what the 2026-08-31 indexing batch covers and, just as importantly, where it stops. The exact release ref is the authority. Hosted `latest` pages are moving references and are not used to silently extend this version.

## Version boundary

These pages target `@tanstack/react-pacer` 0.23.0. The exact release pairs it with core `@tanstack/pacer` 0.22.0. Core classes, options, state, and timing semantics therefore use 0.22.0 behavior.

## Indexed in this batch

- Policy selection, debounce, throttle, rate limit, queue, batch, retry/abort, React patterns, Query-prefetch recipes, persistence/devtools/API map, and lifecycle failures

## Deferred

- One page for every generated core class/function/interface and every React hook
- Preact, Solid, and Angular adapters
- Every official React example and devtools protocol detail
- Pacer Lite and package-author bundle analysis

## Not present in the exact-version documentation

- A repository `llms.txt` at this ref
- A dedicated migration guide
- A policy that preserves every call while also dropping or sampling calls

## Stopping point

This batch stops at the prioritized implementation paths above. Deferred material should be added only when a task needs it, using the same immutable ref and one retrieval-oriented page per coherent topic. Generated symbol references remain discoverable through the official index; they are grouped here rather than copied one file per symbol.
