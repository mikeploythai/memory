# Bootstrap and tooling

This page records the React, file-based setup documented for TanStack Router v1.
The package versions are independent: the matching stable releases include
`@tanstack/router-plugin` 1.168.35 and Router Devtools 1.167.1.

## Requirements

- React 18 or later with `createRoot` support.
- ReactDOM 18 or later.
- TypeScript 5.3 or later is recommended, though not mandatory.
- The docs aim to support the latest five TypeScript minor versions.

## Scaffold a project

The shortest official path is interactive:

```sh
npx @tanstack/cli create --router-only
```

The prompts select file-based or code-based routing, TypeScript, styling,
tooling, and optional Git initialization. File-based routing is the documented
recommendation for most applications.

## Add Router to an existing Vite project

```sh
npm i @tanstack/react-router @tanstack/react-router-devtools
npm i -D @tanstack/router-plugin
```

Configure the Router plugin before the React plugin:

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { tanstackRouter } from '@tanstack/router-plugin/vite'

export default defineConfig({
  plugins: [
    tanstackRouter({ target: 'react', autoCodeSplitting: true }),
    react(),
  ],
})
```

## Required files

Create these files for the documented file-based example:

```text
src/
├── main.tsx
└── routes/
    ├── __root.tsx
    ├── index.tsx
    └── about.tsx
```

The plugin generates `src/routeTree.gen.ts`. Do not hand-edit that file.

```tsx
// src/main.tsx
import ReactDOM from 'react-dom/client'
import { RouterProvider, createRouter } from '@tanstack/react-router'
import { routeTree } from './routeTree.gen'

const router = createRouter({ routeTree })

declare module '@tanstack/react-router' {
  interface Register {
    router: typeof router
  }
}

ReactDOM.createRoot(document.getElementById('root')!).render(
  <RouterProvider router={router} />,
)
```

The host HTML must contain `<div id="root"></div>`.

## Verification and gaps

The quick start says to start the host project's development server. The manual
page also states that the route tree is generated by the Router plugin while
the host `dev` or `build` script runs. It does not provide a universal scripts
block because scripts depend on the selected bundler.

Verification evidence available from the docs is therefore:

1. `@tanstack/react-router` appears in `package.json`.
2. `src/routeTree.gen.ts` is generated when the configured tool runs.
3. `/` and `/about` render and the documented links navigate between them.

The exact `npm run dev` and `npm run build` commands must come from the host
Vite, Rsbuild, Webpack, or Esbuild project.
